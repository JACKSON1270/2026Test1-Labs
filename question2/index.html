AJAX Implementation with jQuery

Problem: The original system loaded very slowly because it retrieved all information from the server synchronously, blocking the page until data was ready.

Solution: By implementing AJAX (Asynchronous JavaScript and XML) technology using jQuery methods, data is loaded asynchronously from the server. This means the page loads immediately, and student data is fetched in the background without blocking the user interface, significantly improving response times.

How it works:
  1. The client (this HTML page at 10.10.10.2) sends an AJAX request using $.ajax() jQuery method
  2. The request goes to fetch_students.php on the server
  3. The PHP script connects to the database at 10.10.10.1 and retrieves student records
  4. Data is returned as JSON and dynamically rendered into an HTML table without a full page reload
